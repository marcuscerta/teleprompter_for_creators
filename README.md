# Teleprompters for Creators

A simple iPad teleprompter. One static web page, works offline once loaded, no accounts.

- Paste or import a script, tap **Start**
- Smooth auto-scroll, speed / size / width / line spacing, reading-line guide, countdown
- **Mirror** and **Flip** for beam-splitter teleprompters (e.g. Neewer X11)
- Bluetooth remote (e.g. Satechi R2): it sends normal keyboard keys; use **Learn** to map any button to any action
- **Camera behind the text** (front camera by default) so you can see yourself while you read, with **Record** (camera + microphone, saved via the iPad share sheet). Asks for the highest resolution the iPad offers; the actual resolution shows on screen
- Tap the text to play/pause, drag to scrub, controls auto-hide so AirPlay/HDMI output stays clean

## Install on iPad
1. Host the folder over HTTPS (e.g. GitHub Pages: Settings → Pages → deploy from branch).
2. Open the URL in Safari → Share → **Add to Home Screen**.

Default remote keys: PageDown/→/Space/Enter play-pause · PageUp/← back · ↑ faster · ↓ slower · `R` record · `.` blank screen · Esc exit.
